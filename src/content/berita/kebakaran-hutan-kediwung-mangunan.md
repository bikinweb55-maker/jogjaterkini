Peristiwa kebakaran hutan melanda kawasan perbukitan Kediwung, Kalurahan Mangunan, Kapanewon Dlingo, Kabupaten Bantul pada Selasa malam (3/11/2026). BANTUL — Jogja Terkini

Hingga Selasa malam, Badan Penanggulangan Bencana Daerah (BPBD) Kabupaten Bantul bersama unsur pemadam kebakaran dan relawan setempat masih fokus melakukan upaya pemadaman serta penyisiran lokasi guna memutus penyebaran titik api.

## Kronologi dan Penyisiran Titik Api di Perbukitan

Berdasarkan informasi awal dari warga sekitar, kepulan asap tebal yang disertai kobaran api mulai terlihat membumbung dari salah satu sudut perbukitan Kediwung pada Selasa sore menjelang malam. Angin yang berembus cukup kencang di area perbukitan membuat material semak dan ranting kering di lahan vegetasi tersebut terlahap api dengan cepat.

Mendapat laporan warga, tim gabungan dari BPBD Bantul, Pemadam Kebakaran (Damkar), TNI/Polri, serta komunitas relawan kebencanaan langsung diterjunkan ke lokasi kejadian.

Akses medan perbukitan yang curam serta keterbatasan pencahayaan di malam hari menjadi tantangan utama petugas gabungan dalam menjangkau titik pusat kebakaran dan melokalisasi kobaran api agar tidak meluas mendekati pemukiman warga maupun kawasan objek wisata.

## BPBD Bantul Masih Selidiki Penyebab Kebakaran

Hingga Selasa malam, pihak BPBD Kabupaten Bantul belum memberikan keterangan resmi terkait penyebab pasti munculnya titik api di perbukitan Kediwung tersebut.

Petugas masih mengutamakan penanganan darurat dan memastikan seluruh kobar api benar-benar padam (*cooling down*) untuk mengantisipasi potensi munculnya titik api susulan akibat gesekan vegetasi kering atau sisa pembakaran.

> "Fokus utama petugas di lapangan malam ini adalah penanganan dan melokalisasi api agar tidak meluas. Untuk penyebab pasti kebakaran serta luas total area terdampak, masih menunggu asesmen lengkap dan penyelidikan tim di lapangan."
>
> — Petugas Tim Reaksi Cepat (TRC) BPBD Bantul

## Imbauan Waspada Kebakaran Lahan di Kawasan Perbukitan

Peristiwa kebakaran hutan di kawasan Kediwung Mangunan ini menjadi peringatan bagi masyarakat luas, khususnya yang beraktivitas di sekitar wilayah perbukitan kering dan hutan kayu.

Pemerintah Kabupaten Bantul dan BPBD mengimbau warga maupun pengunjung kawasan wisata untuk:

1. **Tidak Membakar Sampah:** Hindari aktivitas pembakaran sampah atau lahan secara sembarangan di dekat vegetasi kering.

2. **Hindari Membuang Putung Rokok:** Pastikan tidak membuang puntung rokok yang masih menyala di area semak atau kawasan perbukitan.

3. **Segera Lapor:** Segera menghubungi posko BPBD Bantul atau pemadam kebakaran terdekat jika melihat kepulan asap atau potensi kebakaran lahan.

Bagi masyarakat yang ingin memantau pembaruan informasi kondisi kebencanaan, cuaca, serta imbauan resmi di wilayah DIY, pembaruan dapat diakses melalui saluran komunikasi resmi BPBD Bantul dan Pemkab Bantul.
